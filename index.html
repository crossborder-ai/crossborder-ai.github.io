怎么安装 README 同步版

安装

按 README 的安装命令执行即可。安装时会自动配置国内镜像，并把运行所需内容装到本机。

启动

安装后直接在终端输入 crosspilot。它会自动拉起本地服务并打开浏览器。

关闭

关闭浏览器标签页后，服务会在约 30 秒后自动停止；也可以按 README 里的方式手动退出。

仓库链接

安装包仓库：github.com/crossborder-ai/CrossPilot-releases

版本说明、安装命令和使用步骤见公开 release 仓库 README。

README 同步版

前提条件

CrossPilot 需要本机已有 Node.js 22+。当前安装包已内置生产依赖，正常安装不需要现场安装 npm 依赖；建议同时安装 bun 作为兜底。

先检查本机是否已满足

node -v bun -v

如果 `node -v` 显示 `v22.x` 或更高，可以直接运行下面的 CrossPilot 一键安装命令。

macOS 已安装 Homebrew

brew install node@22 bun brew link --overwrite --force node@22 node -v bun -v

没有 Homebrew

curl -fsSL https://fnm.vercel.app/install | bash source ~/.zshrc 2>/dev/null || source ~/.bashrc 2>/dev/null || true fnm install 22 fnm use 22 curl -fsSL https://bun.sh/install | bash source ~/.zshrc 2>/dev/null || source ~/.bashrc 2>/dev/null || true node -v bun -v

如果安装后当前终端仍提示 `node` 或 `bun` 找不到，关闭终端重新打开后再执行检查命令。

一键安装 / 更新

curl -fsSL https://raw.githubusercontent.com/crossborder-ai/CrossPilot-releases/main/install.sh | bash

同一条命令既用于首次安装，也用于后续更新。脚本会下载最新构建包、使用包内置运行时依赖、注册 `crosspilot` 命令并拉起服务。本地 Node 架构不兼容时才会尝试修复或安装依赖。

日常启动

crosspilot

安装后在任意终端运行这一行即可；脚本会自动检查服务是否已运行，必要时启动并打开浏览器。

关闭

关闭浏览器标签页后，服务会在约 30 秒无心跳后自动退出，不需要常驻终端。

领星配置

  1. 先启动 CrossPilot，再打开本地页面。
  2. 进入设置页里的 LingXing / 领星配置区。
  3. 按页面提示填写 MCP URL 和 Key，并保存。
  4. 做一次连接测试，成功后再回到聊天页使用。

环境变量

变量 说明 默认值
CROSSPILOT_INSTALL_DIR 安装目录 ~/CrossPilot-app
CROSSPILOT_DATA_DIR 数据目录 ~/.crosspilot
CROSSPILOT_PORT 监听端口 3456
CROSSPILOT_MIRROR 是否强制使用 npmmirror 镜像 自动探测
